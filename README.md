# Punnett Square Calculator

A Python program that generates Punnett squares and calculates genotype and phenotype ratios.

## About

I got the idea for this project during a biology class when we were learning about Punnett squares. I thought it would be interesting to recreate the process using Python, so I decided to give it a try.

## Features

- Generates Punnett squares
- Validates user input
- Calculates genotype and phenotype distributions
- Displays genotype and phenotype ratios

## Example

**Cross:** Aa × Aa

|   | A | a |
|---|---|---|
| A | AA | Aa |
| a | Aa | aa |

**Genotype ratio:** 1:2:1

**Phenotype ratio:** 3:1

## How to Run

Make sure Python 3 is installed, download the repository and run:

`python punnett_calculator.py`
